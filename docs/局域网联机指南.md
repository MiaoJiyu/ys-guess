局域网联机使用项目自带的本地 Node.js 服务，不经过 EdgeOne 云端。

## 1. 房主启动服务

在房主电脑上进入项目目录：

```bash
npm start
```

或双击 `start.bat`。

启动成功后会显示：

```text
本地访问：http://localhost:8787
局域网访问：http://<本机IP>:8787
UDP 发现端口 41234
```

自定义端口：

```bash
node server.js 8788
```

其他玩家访问：

```text
http://<房主局域网IP>:8788
```

## 2. 放行防火墙

Windows 首次启动 Node.js 时如果弹出防火墙提示，请允许“专用网络”。

需要放行：

- TCP `8787`：网页与 API 访问。
- UDP `41234`：局域网房间发现广播。

如果其他玩家打不开页面，通常是 Windows 防火墙拦截了 Node.js。

## 3. 同一局域网内加入

所有玩家需要连接同一个 Wi-Fi 或同一个路由器网络。

操作流程：

1. 所有玩家打开 `http://<房主IP>:8787`。
2. 注册或登录账号。
3. 房主点击“联机大厅”→“创建房间”→选择“局域网房间”。
4. 其他玩家进入“联机大厅”→“局域网房间”页签。
5. 点击“刷新列表”，再点击房间卡片上的“免密进入”。

局域网房间不需要输入密码。

注意：局域网房间应通过大厅卡片进入，不建议使用“输入房间号加入”。当前安全校验要求携带局域网发现令牌，手动输入房间号可能提示“局域网房间校验失败”。

## 4. 房间发现失败时

依次检查：

- 是否连接同一个 Wi-Fi / 局域网。
- 是否访问的是房主电脑的局域网 IP，而不是 `localhost`。
- Windows 防火墙是否允许 Node.js 的专用网络访问。
- UDP `41234` 是否被占用或被安全软件拦截。
- 路由器是否开启了“AP 隔离/客户端隔离”。开启后设备之间无法互相访问。
- 同一台电脑不要同时启动多个本地服务实例，UDP 发现端口会冲突。

可以先用以下地址确认房主服务是否可达：

```text
http://<房主IP>:8787/api/health
```

正常会返回包含 `"ok":true` 的 JSON。

## 5. 数据与公网模式的区别

- 局域网模式的账号、房间、战绩保存在房主电脑的 `data/local-kv.json`。
- 局域网数据不与 EdgeOne 云端 Blob 数据同步，排行榜也是本地独立数据。
- 局域网房间只适合同一网络内玩家。
- 异地联机请使用 EdgeOne Makers 部署地址，在“公网房间”中创建和加入。
- 局域网广播无法跨公网工作，云端部署也无法直接发现局域网房间。
